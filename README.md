## About

A shopping list-style app scaffold that introduces Android Fragments and Material Design components. The project explores how to structure a multi-screen app using `Fragment` classes, set up a `Toolbar` as the action bar, and use a `FloatingActionButton` with a `Snackbar` response — the foundation for building list-based apps.

## Concepts Covered

- `Fragment` basics — `FirstFragment` and `SecondFragment`
- Setting a `Toolbar` as the support action bar with `setSupportActionBar`
- `FloatingActionButton` and its click listener
- `Snackbar` for non-intrusive user feedback
- Options menu inflation with `onCreateOptionsMenu` and `onOptionsItemSelected`
- Material Design component integration (`com.google.android.material`)

## Tech

- Language: Java
- Min SDK: Android 5.0+
